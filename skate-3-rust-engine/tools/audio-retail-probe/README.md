# Independent TU3 audio comparisons

These offline Windows probes execute the owned TU3 PPC instruction translation with the owned mapped executable's constants. None of these probes calls the Rust implementation or uses another audio port for expected outputs. No game is launched. Native bodies and output vectors are private build artifacts; do not check them in.

Requirements: Clang with MSVC libraries, the matching rexglue SDK (including SIMDE), generated TU3 `skate3_recomp.*.cpp` files, and the mapped TU3 image beginning at guest address 0x82000000. `generate.py` rejects an image whose SHA-256 differs from the audited image. The provenance sidecar records the compiler, image, translation bodies and vector hashes. This records provenance; it does not certify the instruction translator itself.

Run `python generate.py gain --generated <generated-dir> --sdk <rexglue-sdk-dir> --image <mapped-TU3-image> --out <private-output-dir> --clang <clang++.exe>`.

Set `SKATE_RETAIL_GAIN_VECTORS` to the resulting `gain-vectors.txt`, then run `cargo test -p skate-audio --test retail_gain -- --ignored --nocapture`. It requires all 4,096 blocks and checks 1,048,576 sample bit patterns against the native outputs, including both available Rust dispatch paths. ABI spills may be omitted only in this isolated leaf probe because its caller discards the registers.

Run the generator with `mixmap_input` for a second corpus; set `SKATE_RETAIL_MIXMAP_INPUT_VECTORS` to `mixmap_input-vectors.txt` and run `cargo test -p skate-audio --test retail_mixmap_input -- --ignored --nocapture`. This executes the native tick's input stage for all 32,768 Q15 inputs and ten curve kinds (327,680 cases), checking shaping and millibel conversion. Downstream record counts are deliberately zero. Real GPR spills/restores are provided; unexpected calls abort.

The `mixmap_full` probe additionally requires `--mxb <owned-MixMapSK8.mxb>`. It executes the native builder, reference resolver, initialization and tick functions, with a private guest-memory allocator and host registration callbacks. Unexpected external calls or unmapped guest accesses fail loudly; Windows error popups are disabled. Its output is `mixmap_full-vectors.bin`. Set `SKATE_RETAIL_MIXMAP_FULL_VECTORS` to that file and `SKATE_RETAIL_MXB` to the same MXB, then run `cargo test -p skate-audio --test retail_mixmap -- --ignored --nocapture`.

The stateful corpus runs 1,024 evaluations over all 247 controllers, covering zero/full-scale/rising/falling/random inputs, variable frame intervals, enabled/disabled outputs, and changing distance/azimuth/relative velocity/activation in the 75 native spatial input blocks. Each tick compares all 16 output words per controller: 4,046,848 words. It supplies the free-skate instance counts as host configuration; this does not independently prove which instance counts gameplay chooses. The corpus changes camera modes (-1 and 0..15); all possible state sequences are not certified. The native builder and evaluator are independently executed; the probe's allocator replaces memory management, not mixing algorithms.

These probes do **not** verify gameplay senders, sample decoding, full ambience playback, speech selection, music playback, or device output. Format validation and comparisons between two ports remain useful regression checks, but are not independent retail behavior proofs. Missing vectors fail an explicitly requested ignored test rather than silently skipping it.

The `ambience` probe executes the three native phase/input functions with supplied region results, zone durations, and resource/voice callbacks. Set `SKATE_RETAIL_AMBIENCE_VECTORS` to `ambience-vectors.txt` and run `cargo test -p skate-audio --test retail_ambience -- --ignored --nocapture`. It checks 2,048 ticks of phases, both timer bit patterns, quantized input and start/stop events, including returns to a fading zone and zero-duration fades. It deliberately excludes resource loading, graph construction, spatial region lookup and audible playback; the callbacks count commands rather than rendering sounds.

The `jump` probe executes native conditioner `82772D30` with the owned vault's exact Float-array words `3ee66666` and `3f400000` (class `A867FBE3454326FF/default`, field `468752B0BEE65CDB`). The supplied vault lookup asserts the requested key/index. Set `SKATE_RETAIL_JUMP_VECTORS` to `jump-vectors.txt`, then run `cargo test -p skate-audio --test retail_jump -- --ignored --nocapture`. Its 4,096 strengths include dense bit-pattern neighborhoods on both sides of each cutoff. This checks bucketing, not the animation system that produces jump strength. The game forwards `animation_input.extra.jump_strength`: native common output `82DB6EC0` copies that Processed2624 value into Ground300 before the conditioner reads it.

The `offboard` probe executes `824B0DA8` and compares its state309..319 against `player::bridge::OffboardHold` over 4,096 ticks. Set `SKATE_RETAIL_OFFBOARD_VECTORS` to `offboard-vectors.txt` and run `cargo test -p skate-audio --test retail_offboard -- --ignored --nocapture`. The fixture replaces unrelated scorable, wheel-bucket, body-speed and subsequent MixMap writer calls; those callbacks never read or write the hold-clock bytes. Thus this comparison certifies the hold block for this corpus, not the rest of the bridge. The native animation flag producer and game publication are traced separately.


The `speech_queue` probe executes 82971890 over 4,096 16-slot snapshots. Set `SKATE_RETAIL_SPEECH_QUEUE_VECTORS` to `speech_queue-vectors.txt` and run `cargo test -p skate-audio --test retail_speech_queue -- --ignored`. This verifies channel filtering, strict expiration, independent queue priority, age and serial tie-breaks. Compatibility/follow-up lists and active-line restrictions are excluded.

The `speech_queue_lifecycle` probe executes 82971340/82971DA8/82971890/82971C78 over 4,096 snapshots. Set `SKATE_RETAIL_SPEECH_QUEUE_LIFECYCLE_VECTORS` to `speech_queue_lifecycle-vectors.txt` and run `cargo test -p skate-audio --test retail_speech_queue_lifecycle -- --ignored`. Admission is first-free, first-expired, then first eligible same-channel replacement. Successful dequeue cancels older non-retained same-channel requests. The start callback reports success; it does not render or decode speech.

The `speech_levels` probe executes 824D9370/824DA300 over 4,096 states. Set `SKATE_RETAIL_SPEECH_LEVELS_VECTORS` to `speech_levels-vectors.txt` and run `cargo test -p skate-audio --test retail_speech_levels -- --ignored`. It checks ordinary and focused output-index selection, not the filters, parameter interpolation or audible graph.

The `speech_interrupt` probe executes 824A73F0/824A62F0 over 4,096 cases, with independent control and record channels, stream 0/1/no-stream sentinel 2, active/paused streams, tuning flags and signed priorities. Set `SKATE_RETAIL_SPEECH_INTERRUPT_VECTORS` to `speech_interrupt-vectors.txt` and run `cargo test -p skate-audio --test retail_speech_interrupt -- --ignored`. Vault lookup supplies authored tuning and stop records the native command. Invalid owner indices above sentinel 2 are outside the native caller contract and this comparison.

The `bail_contact` probe executes the whole SkeletonCollision::Fill82BD60C8 with supplied contact-region observations and physical body velocities/weights. Set `SKATE_RETAIL_BAIL_CONTACT_VECTORS` to `bail_contact-vectors.txt` and run `cargo test -p skate-core --test retail_bail_contact -- --ignored`. It compares 4,096 cases with both accumulator bit patterns and all eight region response words. The schema independently maps physics_collision offsets 120/124/128/164 to FBF5CD7734E8AE5A/AD7ECC44569EBEF9/06C10E1F5E1B4730/1430BD50F0A33475. This does not certify the solver/contact producer, HOMBailScorer lifetime or the audio packet that consumes those fields.
